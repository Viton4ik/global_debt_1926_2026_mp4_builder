# Global Government Debt Race (1926 – Oct 2026) | Auto-Installer & Self-Cleaning MP4 Builder

Полностью автономный генератор вертикального видеоролика (**9:16, 1080x1920, 30 FPS, 40 секунд**) в формате `.mp4` со звуковой дорожкой для **YouTube Shorts / Instagram Reels / TikTok**.

## Что делает скрипт `run.py`:
1. **Создаёт временную виртуальную среду** (`.venv_debt_race`) в текущей папке.
2. **Сам скачивает и устанавливает внутрь неё все пакеты**, включая портативный видеокодек **`FFmpeg`** (`imageio-ffmpeg`), поэтому вам **не нужно** ничего устанавливать в систему вручную.
3. **Загружает прямоугольные флаги стран** и строит 100-летнюю матрицу госдолга в долларах США (1926 – октябрь 2026) на основе официальной статистики МВФ и Всемирного банка.
4. **Отрисовывает 1200 кадров (40 секунд)** с плавной интерполяцией без скачков при смене позиций, светло-темным неоново-синим дизайном и легким 3D-эффектом объема.
5. **Генерирует фоновую музыку** в стиле корпоративного синтвейв-эмбиента и сохраняет сертификат свободной лицензии (`MUSIC_LICENSE_CC0.txt`).
6. **Сводит видео и аудио в готовый файл `global_government_debt_1926_2026_shorts.mp4`**.
7. **Полностью удаляет за собой виртуальную среду и все временные файлы**, оставляя вашу систему чистой.

---

## Как запустить (одной командой):

1. Распакуйте архив в любую папку.
2. Откройте терминал (или командную строку) в этой папке и выполните:

```bash
python run.py
```
*(На macOS / Linux может использоваться команда `python3 run.py`)*.

По завершении работы в папке появятся:
- `global_government_debt_1926_2026_shorts.mp4` — готовый 40-секундный видеоролик со звуком.
- `MUSIC_LICENSE_CC0.txt` — файл лицензии на музыку (Public Domain / CC0).
- `YOUTUBE_DESCRIPTION.txt` — готовое описание, заголовки и теги для публикации.
